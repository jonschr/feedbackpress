## What changes

- Pins save several selector candidates and element/content/resource/landmark clues, plus independent document coordinates. Recovery requires an unambiguous match; approximate pins remain movable. Existing stored feedback is never rewritten by recovery. Pin DOM nodes are reused when selecting issues, avoiding a full pin rebuild and preserving pointer interaction.
- Relative page addresses retain the complete query string, including repeated and encoded parameters, through creation, page filtering and next/previous navigation. Previously discarded query values cannot be recovered from older saved paths alone.
- Convert to shared note publishes one human-authored shared comment with the original body/time and protected original agent audit. The API and gateway require `publish:true`, so old tabs with private-conversion wording cannot publish accidentally. Existing private human/earlier converted notes are not automatically published.
- Shared details open immediately from a bounded in-memory/session cache and refresh in the background. Ordinary active entries expire after 30 seconds. A navigation handoff can carry the currently displayed shared list/selection for 30 seconds after leaving, including visible completed rows, without bulk-caching completed history. The session payload remains limited to 200 full entries/1 MiB, including view/known-ID metadata. Private note responses never enter persistent caches. Media uses a separate short-lived in-memory cache, pruned to eight ready entries/20 MiB while retaining an active preview.
- Shared create/reply/edit/status actions are optimistic. IndexedDB plus a synchronous session journal preserve pending shared text/files across document navigation. Progress/success/error cards remain independent of the active issue. Retries use the original operation IDs; stale failures can restore the draft on its original query-bearing page. Private writes use memory-only progress/retry, without persistent private-body storage.
- Up/Down navigate the active issue list, including pagination and query-bearing pages. Status keys 1–4 target the last issue used by mouse movement, explicit selection or keyboard navigation. A stationary pointer, redraw or scroll does not override keyboard selection; one keypress updates one issue. Hover-only rows/pins need no open conversation. Inputs, custom editing controls, modifiers, repeats, composition, placement and modal guards remain in force. This addition is installed with the coordinated update.
- Cross-page review restores the recent list, selected shared issue and list/thread scroll synchronously, refreshes in the background and suppresses repeated drawer entrance animation. Authorized pages preload the shadow stylesheet; controls stay hidden until it is applied. Full activity snapshots use the prior shared-ID inventory to identify genuinely new issues instead of appending old paginated rows. A shared access denial clears restored data; temporary failures retain the known view with an error. Native site navigation remains in place, so the document/assets still need to load. This addition, including the plugin bootstrap preload, is installed.
